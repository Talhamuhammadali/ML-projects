# ML-projects

This repository hosts different machine learning projects where I experiment with various ML models and techniques. It includes toy datasets from different courses on Deeplearning.ai and personal experimentation projects.

## Projects

### Linear Regression

#### 1. CO2 Emissions
- **Location**: `Linear Regression/co2-emission/`
- **Notebook**: `co2_emissions.ipynb`
- Linear regression analysis for predicting CO2 emissions

#### 2. House Prices
- **Location**: `Linear Regression/house-prices/`
- **Notebook**: `single_feature_LR.ipynb`
- Single feature linear regression for house price prediction

#### 3. Diamond Price Prediction
- **Location**: `Linear Regression/diamonds-price-prediciton/`
- **Notebook**: `diamond-price-predictor.ipynb`
- Multi-variable linear regression for predicting diamond prices

#### 4. Time Series Flights
- **Location**: `Linear Regression/time-series-flights/`
- **Notebook**: `flight_prediciton.ipynb`
- Time series analysis for flight delay prediction

#### 5. Coral Analysis
- **Location**: `Linear Regression/Coral-analysis/`
- **Notebook**: `coral.ipynb`
- Time series analysis for coral reef data (Work in Progress)

## Setup

```bash
# Create virtual environment
python -m venv .venv

# Activate virtual environment
source .venv/bin/activate  # On Linux/Mac
# or
.venv\Scripts\activate  # On Windows

# Install dependencies
pip install -r requirements.txt
```
